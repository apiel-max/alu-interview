# Rain

## Description
Given a list of non-negative integers representing wall heights, calculates how many square units of water will be retained after it rains.

## Usage
```python
rain = __import__('0-rain').rain
walls = [0, 1, 0, 2, 0, 3, 0, 4]
print(rain(walls))  # 6
```

## Files
- `0-rain.py` — contains the `rain(walls)` function
